## 一、机器鸭是什么

**Microduck（机器鸭）** 是法国公司 **Pollen Robotics** 做的一款桌面双足机器人。

- Pollen Robotics 2016 年成立，创始团队来自法国 Inria 的 FLOWERS 实验室
- **2025 年 4 月被 Hugging Face 收购**（Hugging Face 借此进入实体机器人领域）
- Microduck 于 **2026 年 8 月 27 日** 发布并开放预售

### 规格

| 项目 | 参数 |
|---|---|
| 售价 | **$399**（税前，不含运费） |
| 身高 / 重量 | **25 cm** / **不到 800 g**（官方商店标 780 g） |
| 自由度 | **15 个舵机** |
| 传感器 | 摄像头 + 小型深度传感器（ToF）+ **两颗 IMU** |
| 执行器 | Dynamixel **XL330** 系列 |
| 主控 | **Radxa Zero 3W**（RK3566） |
| 存储 / 内存 | 32 GB / 1 GB |
| 电池 | 2,600 mAh，约 **1 小时**续航 |
| 连接 | Wi-Fi + 蓝牙 |
| 配色 | Cream / Graphite / Lavender / Sky |

### 它能做什么

走路、坐下、蹲下、**从多种常见摔倒姿态自己爬起来**，甚至**滑旱冰**。
喙是可动的，能**叼起小物件**。

行为策略在物理仿真里训练，可以在**本地**跑，也可以用 **Hugging Face Jobs** 云端训练，
然后直接部署到真机上——官方提供了 **9 个预训练 ONNX 策略**。

### 官方开源了什么？——这是复刻的关键前提

> CNX Software 报道原文：
> *"While the Microduck's software stack is open source, nothing was said about the
> mechanical and hardware design files, and **Pollen Robotics told the press not to
> refer to the robot as 'open-source hardware' (for now).**"*

**翻译一下就是：软件全开源，硬件设计文件官方没放出来，而且官方明确要求媒体别叫它"开源硬件"。**

但有个例外很重要：

| 部件 | 官方开源状态 |
|---|---|
| 运行时 / SDK / 训练栈 / 9 个策略 | ✅ **完全开源** |
| 仿真模型（MJCF + STL） | ✅ 公开 |
| **RPI Robot HAT**（配电 + 音频 + 舵机总线） | ✅ **完整开源，可自己打样** |
| `imu_to_dxl` 小板 | ❌ **未开源，需自绘** |
| 结构件 CAD / 机械设计文件 | ❌ **未开源** |

**好消息是：这套硬件没有不可复刻的部分。** 主控是市售模块，两块自研板里一块已开源、
另一块已被社区逆向出完整元件表，结构件也已被社区从 STL 重建为可编辑模型。

## 二、为什么"自己做一台"比想象的难

### 1. 官方开源的是软件，不是硬件

结构件的 CAD 要靠社区从公开的 STL 网格反向重建。好消息是**已经有人做完了**（见下方资源）。

### 2. $399 是量产价，个人采购拿不到

| | |
|---|---|
| 官方整机 | **$399** |
| 光是 15 颗 XL330 舵机（国内渠道） | 约 **¥4,500** —— **一项就超过整机售价** |
| 社区唯一公开记账的项目实测总支出 | **¥11,923.60** |

**$399 背后是规模化量产 + 官方供应链。零散采购拿不到这个价，差 3–5 倍是常态。**

### 3. 主控是单点瓶颈

Radxa Zero 3W 在 2026 年 9 月处于**断货 + 溢价**状态，国内渠道溢价 3–6 倍。

### 4. 有些零件要自己打板

`imu_to_dxl` 板官方没开源，需要自己画 PCB 并打样。

## 三、两条路线（动手前必须先定）

这是整个项目**最重要的一个决定**，因为它决定你买什么舵机、打印哪一版结构件 —— **两者的零件不能混用**。

| | **路线 A · 原版 XL330** | **路线 B · 国产飞特 HD-1910** |
|---|---|---|
| 舵机 | Dynamixel XL330-M288-T ×15 | 飞特 HD-1910-C001 ×15 |
| **舵机成本** | 约 **¥4,500** | 约 **¥1,845**（¥123/颗） |
| 官方 9 个预训练策略 | ✅ **直接能跑，不用重训** | ❌ **必须自己重训** |
| 训练算力要求 | 无 | ⚠️ **需要 NVIDIA 显卡**（或 HF Jobs） |
| 力矩 | 6.1 kg·cm @6V | **12 kg·cm @6V（约 2 倍）** |
| 工作电压 | 额定 3.7–6.0 V，官方**超压**跑 6.6–8.2 V | ✅ **原生 4–8.4 V**，正好匹配 2S 电池 |
| 运行时软件 | 跑官方代码即可 | ⚠️ **必须用 fork**（协议不兼容，见下） |
| 结构件版本 | CAD 仓库 `v1.1 XL330 版` | CAD 仓库 `v2.1 飞特版` |
| 社区验证 | ✅ 已有项目跑通全部 9 个策略 | ⚠️ 代码已写、测试已过，但**还没上过真机** |

### 怎么选

- **没有 NVIDIA 显卡** → **只能选 A**（路线 B 的策略重训这一关过不去）
- **只想先让鸭子站起来走两步** → 选 A
- **预算敏感，或者本来就想学强化学习训练** → 选 B

### ⚠️ 一个必须澄清的常见错误说法

网上流传"HD-1910 在总线上按 XL330 协议工作，`robotd` 不用改一行代码"——

**这是错的。** 飞特官方协议手册证实两者**结构上不兼容**：

| | XL330（Dynamixel Protocol 2.0） | HD-1910（飞特 SCS/STS） |
|---|---|---|
| **字头** | `FF FF FD 00`（**4 字节**） | `FF FF`（**2 字节**） |
| **校验** | **CRC-16** | **`~(ID+LEN+INST+参数)`** 取反和 |
| 位置寄存器 | 132 读 / 116 写 | **56 读 / 42 写** |
| 运行模式寄存器 | 11 | 33 |
| IMU | 挂总线 ID 200 | **总线上没有 IMU** |

**走路线 B 就必须用 `feetech` 分支的 fork 运行时。**

> 那个假消息的来源：某内容农场把一份严谨研究文档里"官方运行时期望的总线叫
> Dynamixel-compatible"误读成了"第三方舵机兼容"。**一个定语，差了几十小时工作量。**

## 五、施工流程概览

完整版见 [`docs/SOP-施工流程.md`](docs/SOP-施工流程.md)。

```
阶段 0  路线决策     ← 先做这个，写死一个选择
阶段 1  采购         ← 含预算现实（实测案例 ¥11,923.60）
阶段 2  3D 打印
阶段 3  舵机预配置   ← ⚠️ 必须在机械装配之前做完！
阶段 4  机械装配     （01 躯干 → 15 右踝脚）
阶段 5  电控         （打样官方 HAT / 或飞线方案）
阶段 6  系统烧录     （做卡工具已社区化）
阶段 7  软件部署
阶段 8  校准验收
```

### ⚠️ 三个最容易踩的顺序陷阱

1. **舵机 ID 配置必须在上螺丝之前** —— 装进结构件再改要全部拆开
2. **路线选错，打印件全废** —— 两款舵机舵盘凸凹相反，配合件不能混用
3. **电池型号别信文件名** —— 上游打印件里有个叫 `np_f970` 的文件，实际用的是 **NP-F550**；
   真 F970 厚 60 mm **装不进去**
